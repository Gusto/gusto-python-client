# WorkweekStartDay

The day of the week that this pay schedule's workweeks start on, used for regular rate of pay overtime calculations.


## Example Usage

```python
from gusto_embedded_v_2026_06_15.models import WorkweekStartDay

value = WorkweekStartDay.SUNDAY
```


## Values

| Name        | Value       |
| ----------- | ----------- |
| `SUNDAY`    | Sunday      |
| `MONDAY`    | Monday      |
| `TUESDAY`   | Tuesday     |
| `WEDNESDAY` | Wednesday   |
| `THURSDAY`  | Thursday    |
| `FRIDAY`    | Friday      |
| `SATURDAY`  | Saturday    |
