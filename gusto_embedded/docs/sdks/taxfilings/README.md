# TaxFilings

## Overview

### Available Operations

* [get_tax_filings](#get_tax_filings) - Get all tax filings for a company
* [get_tax_filing](#get_tax_filing) - Get a tax filing for a company

## get_tax_filings

Fetches all tax filing obligations for a company.

scope: `tax_filings:read`

### Example Usage

<!-- UsageSnippet language="python" operationID="get-tax-filings" method="get" path="/v1/companies/{company_uuid}/tax_filings" -->
```python
import gusto_embedded
from gusto_embedded import Gusto
import os


with Gusto(
    company_access_auth=os.getenv("GUSTO_COMPANY_ACCESS_AUTH"),
) as gusto:

    res = gusto.tax_filings.get_tax_filings(company_uuid="<id>", x_gusto_api_version=gusto_embedded.GetTaxFilingsHeaderXGustoAPIVersion.TWO_THOUSAND_AND_TWENTY_FIVE_MINUS_06_MINUS_15, include_amendments=True, sort_by="period_start:asc")

    # Handle response
    print(res)

```
